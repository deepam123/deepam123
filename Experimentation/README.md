### Causal Inference Toolkit

**[github.com/deepam123/causal-inference-toolkit](https://github.com/deepam123/causal-inference-toolkit)**

A reusable Python toolkit for causal inference methods built for production analytics:

- Hierarchical Bayesian experimentation
- Difference-in-differences
- Propensity score matching
- Synthetic controls

Built to bring 3x experiment velocity to teams running A/B and quasi-experimental programs at scale.
